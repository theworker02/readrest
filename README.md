# readrest

Read structured JSON rest payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/readrest/

## Install / run

```bash
git clone https://github.com/theworker02/readrest.git
cd readrest
node src/cli.js
node --test
```
